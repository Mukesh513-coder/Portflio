# Mukesh Paul — Portfolio

A responsive, dependency-free portfolio for Mukesh Paul, built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start a local server from this directory:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Portfolio, experience, projects, education, and certification sections
- Responsive navigation and layouts
- Browser-viewable resume PDF and profile photo
